# NepARENA

Nepal's multi-organizer esports platform.

**Production:** [https://neparena.xyz](https://neparena.xyz)

## Stack

- React + TypeScript + Vite / TanStack Router
- Tailwind CSS
- Supabase (Auth, DB, Realtime, Storage)
- Vercel (deploy from `main`)

## Develop

```sh
git clone https://github.com/aashish46ak-lab/NepARENA.git
cd NepARENA
npm install
npm run dev
```

## Build

```sh
npm run build
```

Deploy branch: **`main`** only. Custom domain: **neparena.xyz**.
